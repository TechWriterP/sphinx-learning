Common Sphinx build commands¶

Use this reference to look up common commands for building Sphinx documentation.

Commands¶

.\make.bat html

Builds the HTML version of the documentation.

.\make.bat clean

Removes generated build output so you can rebuild from a clean state.

sphinx-build -b html source build\html

Builds HTML directly by calling sphinx-build with the HTML builder.

sphinx-build -M html source build

Runs Sphinx in make-mode and builds HTML output.

Notes¶

  • sphinx-build reads configuration from conf.py in the source directory.

  • Builders control the output format, such as HTML.

  • On Windows, make.bat is the usual helper script generated by sphinx-quickstart.
